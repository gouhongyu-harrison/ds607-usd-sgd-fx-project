# Statement on Generative AI Usage

In accordance with the DS607 Group Project Guidelines, this document provides transparent disclosure regarding the use of Generative AI tools in this project.

## 1. Tools Used
- **Gemini**: Used primarily as a coding assistant and writing support tool for this project.

## 2. Scope of Application
- **Code Refactoring and Syntax Checking**: Assisting with Python code structure, function refinement, and validation of statistical implementation details.
- **Data Analysis and Experiment Workflow**: Supporting exploratory coding, test design, and debugging of inference-related scripts.
- **Markdown and Documentation Formatting**: Improving the organization and readability of project documents, including the GitHub README and summary materials.

## 3. Human Verification and Audit
- All core statistical methods, empirical logic, hypothesis testing decisions, and final interpretations were designed, reviewed, and verified by team members.
- The final project output was checked manually by the team to ensure correctness, consistency, and alignment with DS607 course requirements.
- Generative AI was used as an assistive tool only; it did not replace the team’s own analysis, judgment, or verification.
